Built-in data covers Scrap Mechanic's 204 unlockable garments, with obtain-sources cross-referenced from the official wiki. Garment Box items drop randomly when you craft at a Dressbot (Garment Box + Cotton); Balloon Chest items are the Tactical set found in Underground balloon chests; Fan Pack DLC items (Brilliant Rider, Logic Hero, Side Bang) are paid DLC and never drop in the world; Promotional / merch sweatshirts come from codes/events.

Rarity (the coloured stripe on each item) is the Garment Box drop tier: Common / Rare / Epic roll from boxes, fixed-source items are "Base", and quest & finish rewards are Legendary. A few newer T-shirts aren't in the wiki yet and default to Common; promo sweatshirts have no listed rarity (shown as "Unknown").

Note: editing the unlock file flips the "owned" flags so items show in the wardrobe, but it does not replay the in-game events Steam watches, so collection achievements won't fire from a hand-made file.

In current game versions the old customization_options.json no longer exists — it's compiled into the binary Cache/Bundle/customization_data.cbo — which is why this tool bakes the list in instead of asking for it.

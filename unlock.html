Scrap Mechanic Character Customisation Tool

This all-in-one webpage will let you unlock outfits in Scrap Mechanic. Based on the description provided at https://outfit-unlocker.sm.gbd.one/ which is no longer available. Just follow the steps below, they should be fairly self-explanatory. Everything happens locally in your browser - no Internet connection required.

1. Game Data

The list of unlockable items is stored in customization_options.json which can usually be found in the following location:

%ProgramFiles(x86)%\Steam\steamapps\common\Scrap Mechanic\Data\Character\customization_options.json

Find customization_options.json and load it here:

2. Descriptions

The descriptions of unlockable items is stored in CustomizationDescriptions.json which can be found in a language-specific location, such as:

%ProgramFiles(x86)%\Steam\steamapps\common\Scrap Mechanic\Data\Gui\Language\English\CustomizationDescriptions.json

Find CustomizationDescriptions.json for your language and load it here:

3. Unlock File

Your unlocked items are stored in a file called unlock inside a subdirectory named User_<STEAMID> where STEAMID is the 17-digit steam id for your Steam account. You should backup the unlock file to save your current progress. These subdirectories can be found in the Scrap Mechanic user data directory, which is typically:

%appdata%\Axolot Games\Scrap Mechanic\User

6. Generate new Unlock File

Click to create a new unlock file with your selection which can be copied over the one you selected in Step 2. Make sure you keep a copy of the original file so you can restore it if there's a problem or you change your mind later!
